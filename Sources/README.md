# Исходники модов

Материалы для разработчиков модов. Готовые установщики и архивы собраны в [разделе для игроков](../README.md#игрокам).

Сохраняем игровую иерархию `<сборник>/Mods/<группа>/<мод>` и раздельные конфиги RU и EN.

- [Redux](Redux/Mods/)
- [Reflection](Reflection/Mods/)
- [Community Mods](Community/Mods/)

Доступные нативные исходники Redux лежат рядом с конфигами и RSON соответствующего мода.

- [UtilityFunctionsPack](Redux/Mods/Tweaks/UtilityFunctionsPack/dll/)
- [ExpAutoSearch](Redux/Mods/Expansion/ExpAutoSearch/dll/)
- [PBEngine и MatrixGame](Redux/Mods/PlanetaryBattles/PBEngine/dll/)

Для RSON пути сборки приведены к относительным. Компилятору и редактору может понадобиться указать путь до локальной папки мода.
