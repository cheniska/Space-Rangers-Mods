# Community Mods

Подборка старых и отдельных интересных модов, которые иначе пришлось бы скачивать по одному.

**[Скачать полный пакет от 27 ноября 2026 года](https://github.com/cheniska/Space-Rangers-Mods/releases/download/community/Community_Mods_Release_2026-11-27.zip)**

Распакуйте архив в папку игры и включите нужные моды. В архиве есть инструкция и список изменений.
