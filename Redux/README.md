# Universe Redux 1.7.0

**[Скачать загрузчик всех частей](https://github.com/cheniska/Space-Rangers-Mods/releases/download/redux-v1.7.0/Download_Redux_1.7.0.cmd)**

Сохраните и запустите `Download_Redux_1.7.0.cmd` в Windows. Он скачает установщик и восемь частей в соседнюю папку `Universe_Redux_1.7.0` и проверит SHA-256. Если скачивание прервалось, запустите загрузчик ещё раз. Когда все файлы будут готовы, откройте `Universe_Redux_1.7.0.exe` из этой папки. Объём загрузки около 7,2 ГиБ.
